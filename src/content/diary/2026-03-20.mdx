## Activation strategy

- Lead with insight, not demo.
- Ask for low-risk sample context first (public PR/issue/thread).
- Show one concrete "decision + gap" output before asking for full repo access.
- Scale a 3-step funnel: start convo -> create curiosity -> show sample output.
